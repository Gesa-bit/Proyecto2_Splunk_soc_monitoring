# 🛡️ Proyecto 2: Monitoreo de Logs y Detección de Amenazas con Splunk (SOC N1)

## 📌 Descripción del Proyecto
Este proyecto documenta la implementación de un entorno SIEM centralizado utilizando **Splunk Enterprise** en Windows para la recolección, análisis e investigación de eventos de seguridad provenientes de un sistema Linux (Ubuntu) en VirtualBox. El objetivo es simular las operaciones diarias de un **Analista SOC N1** en el monitoreo y gestión de incidentes.

* **Mecanismos de Ingesta:** Syslog / Splunk Universal Forwarder.
